About EngFun

EngFun is an interactive and modern English learning platform designed to make learning English more enjoyable and effective for students.

Objectives

This website was created to help students overcome boredom in learning English by providing:

  • Interactive and engaging learning materials
  • Fun quizzes with instant feedback
  • Vocabulary practice through flashcards
  • Daily Word feature to learn new vocabulary
  • Leaderboard to motivate learning

Purpose

EngFun aims to be a helpful tool for students who want to improve their English skills in a fun, modern, and interactive way. This project was developed as a final assignment for the Web Programming course.
